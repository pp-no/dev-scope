# DevScope

Webエンジニア向けの技術系YouTube動画を、カテゴリ別に整理して探せるWebアプリです。

Next.jsやReactなどのフロントエンド技術から、AI活用、インフラ、開発効率化まで、Webエンジニア向けの動画をまとめて検索できます。

---

# なぜ作ろうと思ったのか

最近、AI関連の技術変化がかなり速くなってきて、

「全部追わないと置いていかれるんじゃないか」

という感覚になることが増えました。

YouTubeやXを見れば毎日のように新しい情報が流れてきます。

でも実際には、

- 本当に実務で使われているのか
- 一時的な流行なのか
- 何から見ればいいのか
- どの情報を信じればいいのか

が分からなくなって、逆に疲れてしまうことがありました。

特にYouTubeは便利な反面、情報量が多すぎて、

「結局どれを見ればいいの？」

となることが多かったです。

そこで、

Webエンジニア向けの技術動画をカテゴリ別に整理して、
必要な情報へアクセスしやすくするサービス

を作ろうと思いました。

---

# サービス概要

DevScopeは、Webエンジニア向けの技術動画を検索・整理するためのサービスです。

YouTube上の動画を、

- フロントエンド
- バックエンド
- AI活用
- インフラ
- 開発ツール

などのカテゴリごとに整理して表示します。

単純な動画検索ではなく、

「今どんな技術が話題なのか」

を見つけやすくすることを意識しています。

# 技術選定理由

## Next.js

普段Reactを触ることが多く、
個人開発でも扱いやすかったためNext.jsを採用しました。

App Routerを使うことで、
ページ構成やコンポーネント分割もしやすく、
検索画面やカテゴリページを整理して実装できます。

また、API Routeも使えるため、
YouTube APIとの連携も一つのプロジェクトで完結できます。

## TypeScript

YouTube APIのレスポンスはデータ量が多く、
型がないと管理がかなり大変になるため採用しました。

特に、

- 動画情報
- カテゴリー情報
- APIレスポンス

を安全に扱える点が大きいです。

## Tailwind CSS

個人開発なので、
できるだけ実装スピードを落としたくありませんでした。

Tailwind CSSはUIを素早く組めるため、
今回のような一覧画面中心のアプリと相性が良いと感じています。
